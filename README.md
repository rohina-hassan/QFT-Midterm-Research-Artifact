# QFT Midterm: Critical Exponents in Scalar φ⁴ Theory

## Project Overview

This project investigates the renormalization and critical behavior
of Euclidean massive scalar φ⁴ theory near four dimensions.

The calculations are performed using Mathematica and include
analytical derivations, symbolic computations, and consistency checks.

## Contents

- `QFT_Midterm.nb`: Evaluated Mathematica notebook containing Part 1 and Part 2.
- `equation-map.md`: Mapping of key equations to notebook sections.
- `claims.md`: Main mathematical claims and verification status.
- `experiments.md`: Computational checks and numerical results.
- `environment.md`: Computational environment and dependencies.

## Reproduction

Open `QFT_Midterm.nb` in Wolfram Mathematica and evaluate
the notebook cells in sequence.
